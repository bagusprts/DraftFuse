# DraftFuse

DraftFuse is a cloud-based orchestrator that streamlines real-time data and deployment on scalable infrastructure, automating content lifecycle management.

DraftFuse is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/DraftFuse.git`
2. `cd DraftFuse`
3. Install in editable mode: `pip install -e .`

## Configuration

DraftFuse is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
